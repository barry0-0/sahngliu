02. Deep Dive: Prompt & Agent
AI 核心功能与人机协同载体：Prompt, Agent & Markdown
✍️ Prompt (提示词工程) 沟通与约束
1. 为什么有？大模型需要明确角色与上下文指令，避免回答发散。
2. Markdown 载体：人类易读易写、AI 极为节省 Token 的最佳结构化文本。
3. 为什么要用？约束 AI 输出规范，消除沟通歧义，获得高质量沉淀。
4. 如何使用？给定“角色 + 任务 + 格式限制 + Few-shot 示例”。
💡 详细实战：结构化需求分析模板
将产品经理零散的想法或会议录音，直接转化为标准化的 Markdown PRD 文档。
怎么用：在提示词中给定固定的角色设定、任务指令、输出格式要求和一段参考范例（Few-shot）。
解决什么问题：解决大模型回答过于发散、格式混乱、无法直接落地的业务难题，确保每次输出稳定可用，不再是“废话文学”。
🔥 热门爆款：结构化写需求提示词模板、“你是一个资深架构师...”，瞬间输出专业级文档。
🤖 Agent (自主智能体) 大脑 + 记忆 + 工具
1. 为什么有？单次对话无法完成复杂多步骤与跨软件任务。
2. 用来干什么？自主目标拆解、调用 API / 脚本、自我纠错闭环。
3. 为什么要用？无需人工干预，全自动执行长流程任务。
4. 如何使用？设定目标 ➔ 给定 Tool Call 工具包 ➔ 让 Agent 自主循环。
💡 详细实战：Cursor 多 Agent 协同写代码
打破单次对话限制，多个专业 Agent 在后台互相配合完成庞大的工程代码修改。
怎么用：在 Composer 面板输入“写一个登录页面”，系统自动唤起代码搜索 Agent、编写 Agent 与 Linter Agent。
解决什么问题：实现了“理解上下文 -> 自主搜集信息 -> 自动修改多处代码 -> 自查纠错”的闭环，Agent 像真实的程序员一样拥有执行力和自驱力，大幅替代人工编码环节。
🔥 热门爆款：Devin（全球首个 AI 程序员自动修 Bug）、Manus（自动订机票酒店系统）。
