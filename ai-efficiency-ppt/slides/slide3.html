02. Deep Dive: Prompt & Agent
AI 核心技术深度拆解：为什么用、用来做什么、如何使用 (Prompt & Agent)
✍️ Prompt (提示词工程) 沟通与约束
1. 为什么有？大模型需要明确上下文与角色指令才能精准回答。
2. 用来干什么？限定回答角色、输出格式（如 JSON）与思考链 (CoT)。
3. 为什么要用？防止 AI 幻觉乱答，获得结构化高质产出。
4. 如何使用？给定“角色 + 任务 + 限制 + 样例 (Few-shot)”。
🔥 热门爆款：结构化写需求提示词模板、“你是一个资深架构师...”，瞬间输出专业级文档。
🤖 Agent (自主智能体) 大脑 + 记忆 + 工具
1. 为什么有？单次对话无法完成复杂多步骤与跨软件任务。
2. 用来干什么？自主目标拆解、调用 API / 脚本、自我纠错闭环。
3. 为什么要用？无需人工干预，全自动执行长流程任务。
4. 如何使用？设定目标 ➔ 给定 Tool Call 工具包 ➔ 让 Agent 自主循环。
🔥 热门爆款：Devin（全球首个 AI 程序员自动修 Bug）、Manus（自动订机票酒店系统）。
