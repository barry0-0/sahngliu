02. Early System Agent Practice
早期 AI 尝试：跨端系统级旅游路线 Agent 实践
🗺️ 突破端侧限制 · 一键旅游计划与 Apple Maps 联动
由于当时 iOS/macOS 原生 Apple Intelligence 存在 API 限制，借鉴电脑端 OpenClaw 思想，打造了一款能直接调用系统原生 Apple Maps 地图的旅游计划 Agent。
1. 突破端侧 API 限制与推理调度
绕过本地模型接口约束，通过中间层代理把目的地偏好交由大模型生成结构化行程与 GeoJSON 坐标。
2. 系统级 Schema 唤起 Apple Maps
Agent 计算出导航路径后，自动唤起并直接调用系统原生 Apple Maps，在地图界面无缝渲染景点路线。
💡 核心要点：利用代理调度 + 系统原生 URL Schema，打通 LLM 智能决策与原生 App 调用的能力闭环。 System Level Integration
