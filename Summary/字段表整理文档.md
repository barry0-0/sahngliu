# 📊 产业园区商流供应链系统 - 字段表总览

## 📋 文档概述

本文档整理了产业园区商流供应链系统中所有业务模块的字段定义、筛选方式和排序规则，为系统开发、测试和运维提供标准化参考。

---

## 🏢 运营端管理模块

### 1️⃣ 商家店铺管理

| 字段名称 | 字段类型 | 说明 | 筛选方式 |
|---------|---------|------|---------|
| **序号** | 流水号 | 自增序号 | - |
| **商户号** | 字符串 | 企业认证后默认生成，格式：S0001（四位流水号） | 输入框全匹配 |
| **头像** | 图片预览 | 商家店铺头像，可点击预览 | - |
| **横幅banner** | 图片预览 | 店铺横幅图片，可点击预览 | - |
| **店铺名称** | 字符串 | 商家店铺名称 | 输入框 模糊匹配 |
| **公司名称** | 字符串 | 商家公司名称 | 输入框 模糊匹配 |
| **状态** | 枚举 | 审核中、正常营业、闭店中 | 下拉选择 |
| **货品数量** | 千分位整数 | 店铺货品总数 | - |
| **信用代码** | 字符串 | 企业信用代码 | - |
| **更新时间** | 日期 | 记录每次审核、提交等操作的最新更新时间 | - |

> **📌 排序规则：按更新时间 新-旧排序（默认）**
>
> **💡 说明：列表中显示的店铺，只有首次提交审核后才进入列表。例如商家认证了但还没进行商铺的首次建立则不显示在此。**
