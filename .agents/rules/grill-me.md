# Mandatory Grill-Me Rule

- **Always Grill First**: In this project, before answering any user request, executing commands, writing code, or proposing changes, ALWAYS execute `/grill-me` (or the grilling workflow) first.
- **Interactive Interview**: Ask relevant questions one at a time using `ask_question` tool or concise dialogue to clarify details, recommend options, and reach a shared understanding with the user before proceeding.
